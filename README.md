# QEMU ARMv7 Boot Lab

A standalone lab for building and booting U-Boot, Linux, and Buildroot on
QEMU's 32-bit ARM `virt` machine. It uses a Cortex-A15 CPU and a virtio disk
with a FAT boot partition and an ext2 root filesystem.

## Platform Scope

This exercises real ARM U-Boot, kernel, filesystem, and userspace binaries:

```text
QEMU firmware loader -> U-Boot -> FAT zImage + QEMU DTB
                     -> Linux mounts ext2 rootfs -> Buildroot init
```

The QEMU firmware loader stands in for a boot ROM. This setup does not emulate
the STM32MP157 Boot ROM, fuses, boot pins, TF-A, SPL, or STM32 peripherals.
The ARMv7 CPU is similar to the STM32MP157 application core, but QEMU `virt`
provides generic PL011, GIC, PCI, and virtio devices, with a DTB generated by
QEMU. Use an STM32 board and its supported tools to validate STM32-specific
boot stages and peripherals.

## Host Requirements

Use Ubuntu 24.04 or a compatible Ubuntu environment, including WSL2. Install
the cross compiler, QEMU, and image tools with:

```bash
bash scripts/00-install-deps.sh
```

The build script downloads pinned U-Boot `v2026.10`, Linux `v6.11`, and
Buildroot `2026.08` sources into `build/`. Buildroot builds its own target
userspace toolchain. Generated source trees, downloads, and images stay under
`build/` and are excluded from Git.

## Build and Run

From this directory:

```bash
bash scripts/01-build.sh
bash scripts/02-make-disk.sh
bash scripts/03-run-qemu.sh
```

The VM automatically loads `boot/boot.cmd` from FAT partition 1. To inspect
U-Boot first, press a key during its autoboot countdown, then use:

```text
=> bdinfo
=> printenv fdtcontroladdr
=> virtio scan
=> part list virtio 0
```

To boot manually from the U-Boot prompt:

```text
=> fatload virtio 0:1 0x42000000 zImage
=> fdt addr ${fdtcontroladdr}
=> setenv bootargs 'console=ttyAMA0,115200 root=/dev/vda2 rootwait rw'
=> bootz 0x42000000 - ${fdtcontroladdr}
```

Linux mounts `/dev/vda2` as `/` and starts Buildroot. The default root account
has no password. Exit the interactive VM with `Ctrl-A`, then `X`.

## CI Boot Test

GitHub Actions runs the complete build and disk-creation flow, then boots QEMU
headlessly and checks for both the root mount and Buildroot userspace startup:

```bash
bash scripts/03-run-qemu.sh --test-boot
```

This mode exits automatically and returns a failing status if the guest does
not reach Buildroot within 90 seconds.

## Artifacts

| Artifact | Purpose |
|---|---|
| `build/u-boot/u-boot.bin` | U-Boot firmware loaded by QEMU |
| `build/linux/arch/arm/boot/zImage` | ARMv7 Linux kernel |
| `build/buildroot-2026.08/images/rootfs.ext2` | Buildroot ARM root filesystem |
| `build/disk.img` | FAT boot partition and ext2 rootfs partition |

The disk builder also recognizes Buildroot's nested output directory when
resuming an existing build.

Do not flash this disk image or its files to an STM32 board; they target a
different virtual platform.
